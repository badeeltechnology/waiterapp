# ServePOS Waiter: Privacy Policy

Last updated: 21 October 2026

ServePOS Waiter ("the app") is a work tool for restaurant staff. It is published by Badeel Technology (Doha, Qatar) and is used only by waiters who have been given an account by their restaurant. The restaurant that runs the ServePOS server is the controller of the data described here; Badeel Technology provides the software.

## What the app collects and why

| Data | Why | Where it goes |
|---|---|---|
| Username (work email or username) | To sign the waiter in | The restaurant's own ServePOS/ERPNext server |
| Password | Sent once at sign-in to the restaurant's server over HTTPS | Never stored on the phone |
| Device token | Keeps the waiter signed in on this phone | Stored encrypted in Android Keystore; the server keeps only a hash |
| Device ID (random, generated by the app), device model, Android version, app version | Shows the waiter and manager which phones are signed in, so a lost phone can be signed out | The restaurant's server |
| Push notification token (Firebase Cloud Messaging) | To ring the phone when a guest calls or an order is ready | The restaurant's server and Google Firebase |
| Orders, table numbers, guest counts, order notes, guest call notes | The waiter's job: taking and tracking orders | The restaurant's server; a copy of unsent orders and the menu is kept on the phone until sent |
| Fingerprint / face unlock | Optional, to unlock the app | Handled entirely by Android. The app never sees or stores biometric data |

The app does not collect location, contacts, photos, microphone or camera data, advertising IDs, or analytics. It contains no ads.

## Sharing

Data is sent only to the restaurant's ServePOS server that the waiter connects to, and push tokens to Google Firebase Cloud Messaging for delivering notifications. Nothing is sold or shared with anyone else.

## Security

All traffic uses HTTPS (release builds refuse plain http). Sign-in tokens are stored in the Android Keystore and are excluded from device backups. The restaurant can revoke any phone's access at any time, and the waiter can sign out other phones from the app.

## Retention and deletion

Signing out deletes the token, cached menu, drafts and unsent orders from the phone. Uninstalling the app deletes everything it stored. Order records on the restaurant's server are kept according to the restaurant's own policy; to have account data deleted, contact your restaurant manager or Badeel Technology.
